# 📁 04: Herança e Abstração na Orientação a Objetos

Este módulo utiliza o projeto de gerenciamento de imóveis para aplicar os conceitos de herança, reutilização de código e classes abstratas em Python.

## 🧠 O que é Herança Simples?

A **Herança Simples** acontece quando uma classe nova (classe filha) herda as características de **uma única classe já existente** (classe pai). 

No nosso código, a classe `ImovelResidencial` é uma herança simples de `Imovel`. Ela ganha automaticamente tudo o que um imóvel comum tem (como nome, valor e endereço) sem precisarmos reescrever o código do zero, permitindo apenas adicionar o que ela tem de específico (como quantidade de quartos e piscina).

## 🚀 Arquivos da Aula

*   **`01-imovel_heranca_simples.py`**: Código inicial que monta a classe pai `Imovel` e aplica a herança simples para criar a classe filha `ImovelResidencial`.
*   **`02-imovel_heranca_multipla.py`**: Evolução do sistema que introduz a herança múltipla (onde a classe `Fazenda` herda de duas classes diferentes ao mesmo tempo) e o uso de classes abstratas.
