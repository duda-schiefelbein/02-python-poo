# 📁 03: Conceitos Básicos da Orientação a Objetos

Este módulo introduz os pilares da Programação Orientada a Objetos (POO) em Python, abordando a criação de classes, definição de atributos, métodos construtores e manipulação de objetos na prática.

## 🚀 Arquivos da Aula

*   **`classe_produto.py`**: Modelagem de uma classe chamada `Produto` utilizando o método construtor `__init__` para gerenciar atributos (como nome, valor, quantidade, marca e modelo). O arquivo também implementa lógica de negócios através de métodos para simular ações de `comprar` e `vender` com controle de estoque.
