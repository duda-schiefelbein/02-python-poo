# 📁 Aula 02: Funções Recursivas e Funções Anônimas

Este módulo aborda conceitos avançados de funções em Python, incluindo recursividade (funções que chamam a si mesmas) e o uso de funções anônimas (`lambda`) combinadas com funções utilitárias como `map` e `filter`.

## 🚀 Arquivos da Aula

*   **`fatorial.py`**: Demonstração de uma função recursiva para calcular o fatorial de um número, estabelecendo o ponto de parada e chamadas sucessivas.
*   **`funcao_lambda_map.py`**: Introdução às funções anônimas (`lambda`) aplicadas em conjunto com a função `map` para transformar elementos de uma lista de números.
*   **`funcao_lambda_filter.py`**: Uso de funções `lambda` combinadas com a função `filter` para filtrar elementos de uma lista com base em uma condição lógica (resto da divisão).
