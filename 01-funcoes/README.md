# 📁 Aula 01: Funções em Python

Este módulo faz parte dos estudos de fundamentos de Python e cobre desde a introdução à criação de funções até o escopo de variáveis e estruturas de decisão aplicadas.

## 🚀 Arquivos da Aula

*   **`funcao_retorno.py`**: Introdução à criação de funções com passagem de parâmetros, retorno de valores (`return`) e tratamento básico de erros (divisão por zero).
*   **`escopo_variaveis.py`**: Demonstração prática sobre o ciclo de vida e visibilidade de variáveis globais e locais dentro e fora de blocos de funções.
*   **`funcoes_aritmeticas.py`**: Criação de funções isoladas para as quatro operações matemáticas básicas (soma, subtração, multiplicação e divisão).
*   **`funcao_calcular.py`**: Consolidação do aprendizado através de uma função principal que gerencia as operações aritméticas utilizando a estrutura `match / case`.
